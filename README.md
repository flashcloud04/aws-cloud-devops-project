# AWS Cloud DevOps Project

A production-style AWS cloud project built using Terraform, Git, GitHub, Docker, and GitHub Actions.

## Goals

- Learn AWS infrastructure
- Implement Infrastructure as Code with Terraform
- Practice Git and GitHub workflows
- Build a multi-service AWS architecture
- Implement monitoring and security
- Build CI/CD pipelines
- Deploy applications using containers and serverless services

## Technologies

- AWS
- Terraform
- Git
- GitHub
- Docker
- GitHub Actions
